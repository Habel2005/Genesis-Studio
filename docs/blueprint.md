# **App Name**: Genesis Studio

## Core Features:

- AI-powered Design & Development Tool Showcase: Highlight the agency's core value proposition, demonstrating conceptually how an AI tool assists with wireframing, design, coding, and site launch to achieve stunning, high-performance web design quickly.
- Interactive Content Sections: Implement all defined landing page sections including Hero, Partners, How It Works, Features, Stats, Testimonials, and CTA with their specific textual, visual, and layout requirements.
- Fixed Navigation & Calls-to-Action: Create a fixed, full-width navbar with navigation links and 'Get Started' buttons, guiding users through the single-page experience and towards engagement.
- Dynamic Hero Headline Animation: Utilize the custom BlurText animation component for the hero section's primary heading, providing a sophisticated word-by-word reveal effect powered by framer-motion.
- Custom Liquid Glass Aesthetic: Apply the defined 'liquid-glass' and 'liquid-glass-strong' CSS effects consistently across badges, navigation elements, buttons, and feature cards for a unique, premium visual identity.
- HLS Video Backgrounds with Fallback: Integrate HLS video streams (via hls.js) for engaging, immersive section backgrounds, ensuring autoplay, looping, muting, inline playback, and appropriate poster image fallbacks for broad compatibility.
- Client Engagement Workflow: Provide prominent calls to action, such as 'Get Started' and 'Book a Call,' linking users to further information or a contact/booking process (e.g., a simple form or external booking link).

## Style Guidelines:

- Primary color: Pristine White (#FFFFFF) for dominant text and interactive elements, reflecting the premium, clean aesthetic.
- Background color: Pure Black (#000000) throughout, as explicitly requested by the user, providing a stark, high-contrast canvas for content.
- Accent color: A subtle, cool periwinkle (#A3A0CC) for delicate highlights, subtext accents, and ethereal glow effects in the liquid glass elements, creating a sophisticated depth.
- Headings: 'Instrument Serif' (serif, italic), configured via Tailwind's `font-heading`, providing an elegant and distinctive flair.
- Body text: 'Barlow' (sans-serif), configured via Tailwind's `font-body`, offering clear, modern readability in varying weights (300, 400, 500, 600).
- Lucide icons are consistently used across all interactive and feature elements, including 'ArrowUpRight', 'Play', 'Zap', 'Palette', 'BarChart3', and 'Shield', ensuring a cohesive visual language fitting the modern aesthetic.
- Single-page structure with distinct full-width sections, some featuring specified heights (e.g., Hero 1000px) and 'chess' alternating layouts for feature presentations. Content is often centered and features careful padding and z-indexing for overlay effects.
- Key animations include the custom 'BlurText' component for the Hero heading, word-by-word fades and blur effects powered by framer-motion, and dynamic HLS video backgrounds.
